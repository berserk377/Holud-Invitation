# গায়ে হলুদ — তাহিয়াদ ও আদিবা

Static invitation site (no build step).

## Edit
- **Phone numbers / photos / date / map**: `config.js`
- **Text**: `index.html`
- Photos: put files in `images/` and list them in `config.js` → `photos`.

## Publish (GitHub Pages)
Repo → Settings → Pages → Source: *Deploy from a branch* → pick the branch, folder `/ (root)` → Save.
